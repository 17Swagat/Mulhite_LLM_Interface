# 🤖 Mulhite

> **WEB APP Available At: https://www.mulhite.com** 

**Mulhite** is an Multi-AI models chat application with AI models like GPT, Gemini, Claude, Deepseek, Mistral and Grok in one place. The 2 key features that **Mulhite** provides are:

1. Ability to **Highlight Text** of the AI Responses for better revision. 
2. Don't understand a particular term in a response, don't just just start asking and make your entire chat long. Just select the portion of text and open up a separate side chat thread (which opens up on clicking on that highlighted text again) and ask related questions on that portion in the side chat thread without polluting the main chat interface.

---

## 🛠️ Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Shadcn UI
- Vercel AI SDK
- Vercel AI Gateway
- Convex (Database & Backend)
- Clerk (Authentication)
